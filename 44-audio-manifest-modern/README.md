# 44 - Audio Manifest Modern

- **فایل اصلی:** `music player - manifest.txt`
- **دسته:** کد آموزشی مفید
- **بازسازی:** Kotlin + Android API 37
- **نسخه:** 1.0.0
- **هدف:** آموزش تنظیمات Manifest برای پخش صوت

## چه چیزهایی اصلاح شد؟

- ساختار Java/XML قدیمی به Kotlin تبدیل شد.
- APIهای منسوخ تا حد ممکن با APIهای فعلی جایگزین شدند.
- اعتبارسنجی، مدیریت خطا و رفتار مناسب نسخه‌های جدید Android اضافه شد.
- کدها و فایل‌های پروژه دارای کامنت توضیحی هستند.
- ساختار package/versionCode ثابت است تا نسخه‌های بعدی روی نسخه قبلی نصب شوند.
- منوی همبرگری سمت راست، تنظیمات، اعلان‌ها، اشتراک، درباره ما، تماس با ما و درباره نرم‌افزار از `shared-ui` تأمین می‌شود.

## پیشنهاد توسعه بعدی

Foreground media service و MediaSession

> این پیشنهاد هنوز به‌عنوان قابلیت اضافه پیاده‌سازی نشده تا تصمیم توسعه هر پروژه جداگانه گرفته شود.
