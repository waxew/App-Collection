# Bootstrap archive — فقط برای سابقه

فایل‌های `generate.part00` تا `generate.part04` بقایای Generator اولیه‌ای هستند که برای تبدیل مجموعه قدیمی `Android Source` به اسکلت ۷۸ پروژه Kotlin استفاده شد.

## وضعیت فعلی

این Generator دیگر منبع حقیقت پروژه نیست و نباید برای بازسازی Source فعلی اجرا شود. از زمان Bootstrap اولیه، سورس واقعی شامل Bug fix، اصلاح Kotlin source set، UI مشترک جدید، Version/Update handling، QA، صفحات مستقل Drawer و تغییرات متعدد دیگری شده است که Generator قدیمی از آن‌ها اطلاع ندارد.

Workflow قدیمی که می‌توانست این Payload را اجرا و Source را بازنویسی کند عمداً حذف شده است.

## دلیل نگهداری فایل‌ها

- ثبت سابقه تبدیل اولیه.
- امکان مطالعه روش مهاجرت فایل‌های قدیمی.
- Traceability فنی، بدون دادن اختیار بازنویسی سورس نهایی.

## قانون

برای توسعه جدید مستقیماً فایل‌های واقعی ماژول‌های شماره‌دار و `shared-ui` را ویرایش کنید. هر تغییر باید طبق `COMMENTING_STANDARD.md` مستند شود و توسط Workflowهای Build/QA بررسی شود.
